# ✅ TaskFlow

### Gerenciador de Tarefas desenvolvido com JavaScript

O **TaskFlow** é uma aplicação web para gerenciamento de tarefas pessoais, desenvolvida com HTML, CSS e JavaScript.

O projeto tem como objetivo aplicar conhecimentos de desenvolvimento Front-end, manipulação do DOM, lógica de programação, versionamento com Git e boas práticas de Engenharia de Software.

A aplicação será aprimorada continuamente, recebendo novas funcionalidades e melhorias em sua estrutura.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## 💻 Como executar

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `index.html` em um navegador.
4. Utilize o formulário para cadastrar suas tarefas.
